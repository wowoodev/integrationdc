# integrationdc (Chrome Extension)

여러 디시인사이드 갤러리의 글을 한 페이지에서 모아보고, 공지 및 광고 글을 자동으로 제외하여 확인할 수 있는 크롬 확장 프로그램입니다.

---

## ✨ 주요 기능

* 여러 갤러리 글 통합 조회
* 공지 / 광고성 글 자동 제외
* 정렬 기능 (최신순 / 추천순 / 댓글순 / 조회순)
* 갤러리 선택 필터 및 전체 선택 기능
* 추천수 필터 기능
* 다크모드 지원

---

## 🚀 사용 방법

1. 확장 프로그램 실행
2. 갤러리 ID 입력 후 추가 (주소창 ?id= 오른쪽 부분 / 쉼표로 여러 개 입력 가능)
3. “통합갤러리 보기” 클릭
4. 정렬 / 필터 기능 활용

---

## ⚠️ 안내 사항

* 디시인사이드 구조상 실시간 반영이 아닐 수 있으며, 새로고침 시 최신 글을 불러옵니다.
* 각 갤러리당 최대 2페이지까지 데이터를 불러옵니다.
* 갤러리 수가 많을 경우 로딩 시간이 길어질 수 있습니다.
* 크롬 확장 프로그램은 모바일 환경에서 동작하지 않습니다.

---

## ⚖️ 비공식 도구 안내

본 프로그램은 디시인사이드와 공식적으로 관련이 없는 비공식 도구입니다.
디시인사이드의 서비스 정책 및 구조 변경에 따라 정상 동작하지 않을 수 있습니다.

---

## 🛠 개발 환경

* Chrome Extension (Manifest V3)
* Vanilla JavaScript

---

## 📌 참고

* 디시인사이드 웹 구조를 기반으로 데이터를 수집합니다.
* 사이트 구조 변경 시 일부 기능이 동작하지 않을 수 있습니다.
